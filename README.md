## 🛠️ Installation

### Requirements

- Python 3.x
- Git
- Linux / Kali Linux (recommended)

### Quick Install

```bash
git clone https://github.com/your-username/hackingtool.git
cd hackingtool
sudo chmod +x install.sh
sudo bash install.sh
```

### Docker

```bash
docker build -t hackingtool .
docker run -it hackingtool
```

## 🚀 Usage

```bash
sudo python3 hackingtool.py
```

Navigate through the menu by entering the corresponding number for each tool category or specific tool.
